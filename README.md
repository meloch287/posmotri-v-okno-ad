# Посмотри в окно

Учебный проект Яндекс Практикума: интерфейс поиска видеозаписей городов по названию и времени суток. Вёрстка выполнена по макету Figma поверх официальной заготовки `posmotri-v-okno-ad`.

Репозиторий: https://github.com/meloch287/posmotri-v-okno-ad

В CSS реализованы фиксированный макет, список карточек с прокруткой, состояния кнопок и ссылок, собственные чекбоксы и видимый клавиатурный фокус. Исходная логика поиска, переключения видео, дозагрузки карточек, прелоадеров и ошибок сохранена.

Для локального запуска откройте `index.html` в современном браузере или запустите статический сервер из корня проекта:

```bash
python3 -m http.server 8763 --bind 127.0.0.1
```

Затем откройте http://127.0.0.1:8763. Для загрузки видео требуется доступ к `https://v-content.practicum-team.ru`.
